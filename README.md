# Week 3 CRUD Todo API

A lightweight RESTful API built with Node.js and Express to manage todo tasks.

## Features
- **GET** `/todos`: Fetch all todo items
- **POST** `/todos`: Create a new todo item
- **DELETE** `/todos/:id`: Remove a todo by ID

## Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your system.
